# Underdark 통합 자동 던전 매크로 & 핀코드 해제기 v2.3 (Desktop App)

모바일 게임 **Underdark**를 LDPlayer에서 자체적으로 자동 파밍할 수 있도록 던전 루프(일반 810 스테이지 노가다 모드 / 심연의 모래 구멍 자동 반복)를 전자동으로 실행하며, 게임 도중 발생하는 **매크로 방지 4자리 숫자 팝업**을 백그라운드에서 실시간 포착하여 자동 해제하고, **게임 튕김 시 자동으로 UnderDark를 재실행**하는 올인원 데스크탑 애플리케이션입니다.

---

## 🌟 주요 기능

1. **🔄 [신규] 게임 비정상 종료(튕김) 자동 감지 및 UnderDark 재실행 & 자동 복구:**
   - 장시간 방치 파밍 중 메모리 누수나 크래시로 게임이 꺼져 안드로이드 홈 화면(바탕화면)으로 나갔을 때를 실시간 감지.
   - 바탕화면의 **UnderDark 앱 아이콘을 자동으로 인식하여 클릭 터치 ➔ 게임 재시작**.
   - 게임 구동 및 로딩 시간(카운트다운) 동안 안정적으로 대기한 뒤, 캠프/로비 진입 시 **중단되었던 매크로 파밍 루프를 자동으로 이어받아 24시간 끊김 없는 무중단 파밍 실현**.
   - GUI 옵션(`🔄 앱 튕김 시 자동 재시작`)을 통해 원클릭 켜기/끄기 지원.
2. **⚡ 일반 810 스테이지 노가다 파밍 모드:**
   - **캠프 화면:** 중앙 하단 [던전] 버튼 자동 클릭
   - **던전 선택:** 상단 [일반] 탭 선택 상태 확인
   - **스테이지 탐색 & 정밀 검증:** 중앙 스테이지 번호 확인 ➔ `Stage 811` 등 다른 스테이지일 경우 `[<-]` 좌측 화살표를 눌러 `Stage 810`(또는 한글 `스테이지 810`)을 자동으로 탐색 및 선택
   - **정확한 입장:** `Stage 810` / `스테이지 810` 확인 시 [소탕] 버튼이 아닌 **우측 [입장] 버튼을 정확히 클릭하여 전투 진입**
   - **웨이브 모니터링:** 게임 진입(1 / 16 wave) 후 실시간 웨이브 진행 모니터링
   - **보스 등장(Final Wave) 시 즉각 포기 루틴:** 15 / 16 wave를 지나 `Final wave` 또는 한글 `마지막 웨이브` 보스 등장 문구가 표시되면 즉시 우측 상단 햄버거 메뉴[≡] 클릭 ➔ 설정창 오픈 ➔ [포기하기] 클릭 ➔ 확인 팝업 [예] 클릭
   - **보상 수령 및 무한 반복:** 패배 화면 [광고 x2] 클릭 ➔ 보상 획득 화면 [확인] 클릭 ➔ 던전으로 복귀하여 지정 횟수 또는 무한 반복
2. **🔥 심연의 모래 구멍 자동 반복 파밍 (랭킹 탭 스마트 탐색):**
   - 상단 [랭킹] 탭 선택 후 아래로 스마트 스크롤하며 `심연의 모래 구멍` 카드 템플릿을 정밀 탐색 ➔ 타 던전 오입장을 방지하고 정확히 [입장] 터치 ➔ 전투 대기 ➔ 광고x2 ➔ 보상 확인 무한 반복
3. **🎮 전투 시작 시 사용자 정의 초기 조작 1회 자동 실행:**
   - 전투 시작 직후 원하는 방향으로 드래그(우/좌/상/하 및 4방향 대각선 총 8방향 지원)를 1회 자동 실행하여 캐릭터 명당 자리 배치 및 진형 구축 가능.
   - 드래그 지속 시간(기본 200ms) 설정 및 `[⚡ 1회 즉시 테스트]` 버튼 지원.
4. **📐 960×960 및 모든 해상도/화면비 자동 적응형 엔진:**
   - 960×960(1:1 정사각형), 540×960(9:16 세로), 720×1280, 1080×1920, 998×994 등 어떤 해상도로 변경해도 세로 높이 기준 동적 배율 및 팝업 앵커 중심 정렬을 통해 100% 완벽 감지.
5. **실시간 매크로 방지 팝업 감지 & 초고속 핀코드 해제:**
   - 던전 진행 또는 로비 어디서든 방지창 발생 시 0.1초 내 즉각 감지.
   - 고정 폰트(0~9) 템플릿 라이브러리 OCR을 통해 5ms 내 4자리 핀코드 추출 후 키패드 초고속 자동 입력.
6. **완전한 백그라운드 제어 (ADB 연동):**
   - 마우스 커서를 빼앗지 않고 안드로이드 내부에서 직접 터치(`input tap`) 및 스와이프(`input swipe`)를 전송하므로, 다른 작업(웹서핑, 코딩 등)을 병행해도 전혀 간섭 없음.
7. **세련된 다크 테마 GUI (PyQt6):**
   - 실시간 화면 프리뷰 (상태별 배너, 타겟 박스 및 조준선 오버레이).
   - 누적 던전 완료 횟수, 핀코드 해결 횟수, 현재 상태, 전투 경과 시간 실시간 통계.
   - 19종 오프라인 샘플 이미지 원클릭 진단 기능 탑재.

## ⚙️ 사전 설정: LDPlayer ADB 활성화

프로그램이 LDPlayer와 백그라운드로 통신하기 위해 ADB 기능이 켜져 있어야 합니다.

1. **LDPlayer 우측 상단 톱니바퀴 (설정) 클릭**
2. **[기타 설정]** 탭 이동
3. **[ADB 디버깅]** 항목을 **`로컬 연결 열기`** 또는 **`ADB 연결 열기`** 로 설정
4. 설정 저장 후 LDPlayer 재시작 (기본 포트: `127.0.0.1:5555`)

## 🚀 실행 및 빌드 방법

### 1. 단독 실행 파일 (.exe)로 바로 실행하기
빌드된 실행 파일은 Python 환경 없이도 단독 실행됩니다:
- `dist/UnderdarkMacroSolver.exe` 파일을 더블 클릭하면 바로 실행됩니다.
- (해당 파일을 바탕화면이나 원하는 위치에 바로가기 만들어 두고 쓰시면 편리합니다.)

### 2. 코드 수정 후 다시 빌드하기
코드를 수정한 뒤 다시 `.exe` 파일로 빌드하려면:
- 루트 폴더의 `build.bat`을 더블 클릭하면 자동으로 최신 코드가 반영된 `.exe`가 생성됩니다.

### 3. 파이썬 개발 모드로 실행하기
```bash
pip install -r requirements.txt
python main.py
# 또는 터미널 창 없이 바로 실행:
run.bat
```

### 4. 사용 방법
1. 프로그램을 실행하면 상단에 현재 구동 중인 LDPlayer 디바이스가 자동 표시됩니다.
2. **`[연결하기]`** 버튼을 누릅니다. (연결 성공 시 초록색 불이 켜집니다)
3. **[동작 모드]**를 선택합니다:
   - `⭐ [일반 810 스테이지] 노가다 파밍 (Final Wave 포기하기 반복)`: 캠프 ➔ 던전 선택 ➔ 일반 탭 ➔ 810 스테이지 탐색 & 우측 [입장] ➔ 웨이브 모니터링 ➔ Final Wave 보스 등장 시 설정창 ➔ 포기하기 ➔ 확인 팝업 [예] ➔ 광고 x2 ➔ 보상 확인을 무한 반복합니다.
   - `🔥 [심연의 모래 구멍] 던전 자동 반복 파밍`: 캠프 ➔ 던전 선택 ➔ 랭킹 탭 ➔ 심연의 모래 구멍 입장 ➔ 전투 대기 ➔ 광고 x2 클릭 ➔ 보상 확인 ➔ 캠프 복귀를 무한 반복합니다.
   - `🛡️ 단독 매크로 방지 핀코드 해제만 (기존 모드)`: 던전 진행 없이 4자리 숫자 방지창만 상시 감지하여 자동 해제합니다.
4. **[🛡️ 매크로 방지 4자리 핀코드 자동 해제]** 체크박스 옵션 설정:
   - **체크 시 (기본값)**: 스테이지 또는 던전 파밍 중 매크로 방지 핀코드가 발생하면 즉시 OCR로 인식 및 자동 터치하여 원스톱으로 해제합니다.
   - **체크 해제 시**: 파밍 중 핀코드가 감지되어도 건드리지 않고 '핀코드 수동대기' 상태로 안전하게 멈춰 대기합니다. (직접 입력 후 창이 닫히면 파밍이 재개됩니다)
5. 필요 시 **반복 횟수**(0: 무제한)를 지정합니다.
6. **`[▶ 매크로 시작]`** 버튼을 누르면 전자동 매크로가 작동합니다.
7. 중간에 **`[오프라인 샘플 진단]`** 드롭다운에서 810 스테이지 단계별 화면 및 기존 화면들을 선택하고 **`[선택 샘플 진단 실행]`**을 누르면 실제 캡처본을 바탕으로 인식 및 타겟 클릭 좌표가 완벽하게 작동하는지 언제든 확인할 수 있습니다.
